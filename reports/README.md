# reports/

Qui ogni agente scrive il proprio riepilogo, usando il formato definito in `REGOLE.md`.

## Nomi

| Agente | File |
|---|---|
| 0 Architetto | `agente-0-architetto.md` |
| 1 Audio | `agente-1-audio.md` |
| 2 Dati | `agente-2-dati.md` |
| 3 Logica | `agente-3-logica.md` |
| 4 UI | `agente-4-ui.md` |
| Integrazione | `integrazione.md` |
| 5 QA | `agente-5-qa.md` |

## Formato

```markdown
# Report — Agente N (Nome)
Stato: completato | parziale | bloccato

## File creati/modificati
## Decisioni
## Deviazioni dal prompt
## Richieste ai contratti
## Test eseguiti (comando + esito)
## Problemi aperti
## Cosa NON ho verificato
```

Il report è l'unico canale di consegna verso il coordinatore: deve essere completo anche
se il messaggio di chat è breve.
